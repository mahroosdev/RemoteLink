# Changelog

## 1.0.0 - Release Candidate

### Included

- Local network discovery, manual IP connection, pairing code validation, and desktop approval.
- Android-to-Windows mouse, click, drag, scroll, keyboard, modifier, and shortcut control.
- Windows screen preview on Android with monitor selection and fullscreen viewing.
- Android screen sharing to the Windows viewer with portrait and landscape updates.
- Exclusive remote modes, clean disconnect recovery, and held-input release safeguards.
- Public-safe activity messages, local-only security boundaries, and release documentation.

### Release Gate

Public binaries require final real-device regression and private Android and
Windows signing. Signing files and credentials are not stored in this repository.
