# RemoteLink Support

## Before Reporting a Problem

1. Confirm the phone and PC are on the same trusted Wi-Fi network or personal hotspot.
2. Start the desktop engine and use the recommended host IP shown by RemoteLink.
3. Approve the phone's pairing request on the PC.
4. If discovery fails, use manual IP connection.
5. If connection still fails, check Local Access in Pairing & Devices.

The in-app Manual contains feature-specific troubleshooting for pairing, input,
PC preview, and phone screen sharing.

## Public Support

Use the repository's GitHub Issues page for reproducible non-security bugs.
Include the RemoteLink version, Windows version, Android version, expected
behavior, and steps to reproduce. Remove pairing codes, local IP addresses,
screen contents, personal paths, and signing information before posting.

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) for
private security reporting.
